# KRUPA Spanish — iOS-версія

iOS-порт застосунку для вивчення іспанської мови (оригінал — Android-застосунок
`ua.krupa.spanish`, Kotlin + Jetpack Compose). Написано з нуля на **SwiftUI**.

- **Цільова платформа:** iOS 17.0 — тобто застосунок працює і на **iOS 17.7**
- **Залежності:** жодних сторонніх бібліотек (лише SwiftUI, Foundation, AVFoundation, Speech)
- **Мережа:** не потрібна — увесь контент курсу вбудовано в застосунок
- **Мова інтерфейсу:** українська, контент — іспанська

## Що вміє застосунок

| Розділ | Опис |
|---|---|
| Навчання | Заняття з блоків: нові слова → повторення → граматика → вправи → аудіювання → говоріння |

| Речення | 432 речення з перекладом і поясненням вимови |
| Вправи | 466 вправ 9 типів: вибір, переклад в обидва боки, пропуски, складання речення, диктант, аудіювання, вимова, пари |
| Граматика | 34 теми з правилами, прикладами, типовими помилками та порадами для україномовних |
| Аудіювання | 22 діалоги/історії з ключовими словами й питаннями на розуміння |

| Резервні копії | Експорт та імпорт прогресу у файл JSON |

## Дві версії застосунку

| Версія | Що це | Кому підходить |
|---|---|---|
| **Нативна** (`KrupaSpanish/`) | справжній iOS-застосунок, збирається у `.ipa` | якщо є Mac або комп'ютер поруч із телефоном; дає оцінку вимови через мікрофон |
| **Веб-версія** (`web/`) | PWA: відкривається в Safari, додається на екран «Домівки» | якщо телефон далеко й безкоштовно: просто надіслати посилання, працює офлайн і без термінів дії |

### Веб-версія: як опублікувати й поділитися

1. Завантажте проєкт на GitHub (див. нижче).
2. У репозиторії: **Settings → Pages → Source = GitHub Actions** (один раз).
3. Після кожного пушу workflow **Deploy web version (PWA)** сам публікує теку `web/`.
4. Посилання для дитини матиме вигляд `https://ВАШ-ЛОГІН.github.io/НАЗВА-РЕПОЗИТОРІЮ/`
   — його можна надіслати у WhatsApp. Інструкція для дитини:
   [install-web-uk.md](docs/install-web-uk.md).

Веб-версія працює офлайн (service worker кешує контент), зберігає прогрес у
пам'яті телефона й має ті самі матеріали: 1492 слова, 432 речення, 466 вправ,
34 теми граматики, 22 аудіювання.

### Локальна перевірка веб-версії (на Windows)

```powershell
node web/test/logic.test.mjs      # 57 тестів логіки на реальному контенті
node web/test/views.test.mjs      # чи імпортуються всі екрани
python -m http.server 8080 --directory web   # перегляд у браузері: http://localhost:8080
```

## Як отримати `.ipa` (без Mac)

Збірка виконується на **безкоштовному macOS-раннері GitHub Actions**.

### 1. Завантажте проєкт на GitHub

Створіть на GitHub порожній репозиторій (приватний або публічний) і завантажте туди
вміст цієї теки:

```bash
cd KrupaSpanish/..           # тека, де лежить .github і KrupaSpanish
git init
git add .
git commit -m "KRUPA Spanish: iOS-версія"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГІН/krupa-spanish-ios.git
git push -u origin main
```

### 2. Дочекайтеся збірки

Після `push` відкрийте сторінку репозиторію → **Actions** → робочий процес
**Build iOS IPA** → після завершення завантажте артефакт
**KrupaSpanish-unsigned-ipa** (файл `KrupaSpanish-unsigned.ipa`).

Збірку можна запускати вручну: **Actions → Build iOS IPA → Run workflow**.

## Як встановити на iPhone (iOS 17.7) з Windows

Файл `.ipa` зібраний **без підпису** — це нормально: підпис ставиться на вашому
комп'ютері під вашим Apple ID.

### Варіант A. Sideloadly (безкоштовний Apple ID)

1. Встановіть [Sideloadly](https://sideloadly.io/) на Windows.
2. Встановіть **iTunes** (з сайту Apple, не з Microsoft Store) — потрібен для драйверів.
3. Підключіть iPhone кабелем, на телефоні натисніть **Довіряти**.
4. Відкрийте Sideloadly: перетягніть `KrupaSpanish-unsigned.ipa`, введіть свій Apple ID.
5. Натисніть **Start**. Sideloadly підпише застосунок і встановить його.
6. На iPhone: **Налаштування → Основні → VPN і керування пристроєм** →
   довіряйте своєму Apple ID.

> **Обмеження безкоштовного Apple ID:** підпис діє **7 днів**, максимум 3 застосунки.
> Після завершення терміну просто повторіть кроки 4–5 — прогрес у застосунку
> збережеться (дані лежать у пісочниці й не видаляються при перепідписуванні).

### Варіант B. Apple Developer (99 $/рік)

Підпис діє 1 рік, доступний TestFlight. Для цього додайте в репозиторій секрети
(див. `.github/workflows/build-ipa-signed.yml`) і запустіть відповідний workflow.

### Варіант C. AltStore

Альтернатива Sideloadly: AltServer на Windows + AltStore на iPhone, той самий
принцип (безкоштовний Apple ID, 7 днів).

## Відмінності від Android-версії

Це не «перепакований» APK (так не буває — Android і iOS несумісні), а **нове
застосунок тією ж логікою й тим самим контентом**:

| Android | iOS |
|---|---|
| Kotlin + Jetpack Compose | Swift 5 + SwiftUI |
| Room (SQLite) | JSON-документ у `Application Support` (ті самі дані, інший носій) |
| Android TTS (`es-ES`, rate 0.5…1.5) | `AVSpeechSynthesizer` (rate 0.2…0.8, тобто та сама шкала ÷ 2) |
| Android SpeechRecognizer (`es-ES`) | `SFSpeechRecognizer` (es-ES) + `AVAudioEngine` |
| Резервна копія — один JSON-файл | Так само: `krupa_spanish_progress_*.json` |
| Нагадування через WorkManager | Не реалізовано (поля в профілі лишилися) |
| AI-діалоги: лише офлайн-провайдер | Офлайн-провайдер + **додатково** будь-який OpenAI-сумісний сервер (вимкнено за замовчуванням) |

### Що відтворено 1:1 (перевірено дизасемблюванням APK)

- **Інтервальне повторення:** крок навчання 10 хв, крок «не знаю» 1 хв, легкість 2.5
  (межі 1.3…2.8), бонуси ±0.15, штраф зриву 0.2, множник «трудно» 1.2, бонус «легко» 1.25,
  випуск через 1 день, «легко» — 4 дні, стеля 365 днів, множник швидкості відповіді
  (0.92…1.1), «вивчено» з 21 дня.
- **Перевірка відповідей:** наголоси та діакритика важливі, регістр і пунктуація — ні
  (як в оригіналі). Толерантність до одруків — розширення порту, вимкнене за замовчуванням.
- **Оцінка вимови:** `0.55 × точність слів + 0.30 × фонетична близькість + 0.15 × плавність`,
  штрафи 1.0 / 0.6 / 0.45, поріг схожості 0.72, фонетична транслітерація
  (ch→ч, ll→й, c/z→θ, j→х, rr→р, h→∅) і 11 типів зауважень.
- **План заняття:** блоки в порядку повторення → нові слова → граматика → вправи →
  аудіювання → говоріння; 8 нових слів і до 60 карток повторення за заняття.
- **Контент:** 1492 слова, 432 речення, 466 вправ (9 типів), 34 граматичні теми,
  22 аудіювання, 24 теми — усе з оригінального APK без змін.

Контент (слова, речення, вправи, граматика, аудіювання) **ідентичний** —
його витягнуто з оригінального APK без змін.

## Перевірка коду перед збіркою

У теці `tools/` є три скрипти (запускати у Windows PowerShell):

```powershell
& tools\check-swift.ps1    # дублікати типів, заборонені конструкції, маршрути
& tools\check-api.ps1      # чи існують викликані члени AppState/сервісів, чи всі екрани на місці
& tools\check-braces.ps1   # точний баланс дужок (враховує рядки, коментарі, """...""")
```

Усі три скрипти нічого не змінюють у коді — лише звітують. Вони проходять чисто
на поточному стані проєкту.

## Якщо хмарна збірка впала

Код писався й перевірявся на Windows, де **немає компілятора Swift**, тому перша
збірка на GitHub — це перша справжня перевірка типів. Якщо вона впала:

1. Відкрийте **Actions → Build iOS IPA → (останній запуск) → крок «Build app (unsigned)»**.
2. Там буде рядок виду:
   `KrupaSpanish/Sources/UI/Screens/SessionScreen.swift:412:31: error: cannot convert value of type ...`
3. Скопіюйте **усі рядки зі словом `error:`** (зазвичай 1–10 рядків) і надішліть їх
   у чат — виправлення буде точковим, без переписування застосунку.
4. Також до артефактів падіння додається файл `xcodebuild-log` із повним логом.

У теці `spec/` лежать документи, відновлені з дизасембльованого APK:

(`_recon/strings_by_class.txt`) — це проміжний артефакт аналізу, у репозиторій не входить.
